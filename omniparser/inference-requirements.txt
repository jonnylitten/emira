# Minimal OmniParser inference dependencies for emira.

# OmniParser's own requirements.txt pulls in gradio, streamlit, anthropic,
# openai, paddlepaddle, etc. — its demo/agent app stack. We only need the
# detector + captioner path. Version floors below are picked to guarantee
# a prebuilt arm64-macOS wheel exists (no source compiles).
#
# Skipped vs OmniParser's full requirements.txt:
#   gradio, streamlit          — demo UI
#   anthropic, openai, dashscope, groq, boto3, azure-identity, google-auth
#                              — multi-LLM agent harness
#   paddlepaddle, paddleocr    — replaced by easyocr (use_paddleocr=False)
#   pyautogui, screeninfo, uiautomation, pymsgbox
#                              — desktop-automation deps for OmniParser's
#                                control demo, not its detector
#   ruff, pre-commit, pytest   — dev tooling
